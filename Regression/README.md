# Regression Projects

This folder contains regression-based machine learning projects implemented
using real datasets and a proper end-to-end workflow.

## Covered Concepts
- Data loading from CSV
- Exploratory Data Analysis (EDA)
- Train-test split
- Model training
- Model evaluation
- Predictions on new data

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn
